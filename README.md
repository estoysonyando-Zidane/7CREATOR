# 七人の創造主 — 世界生成プロジェクト

## これは何か

7人の創造主が、無から1つの世界を作っていく。役割分担はなく、全員があらゆる要素（地形・生き物・歴史・法則・伝承など）に口を出せる。統合や合意形成はしない。矛盾したまま世界は積み上がっていく。

固有名詞（既存作品のキャラクター名など）は一切使わない。人格ラベルのみで演じる。

## 7人の人格

- **理想主義者**：美しくないもの、意味のないものを許せない。無駄な提案には即座に「なぜそれが必要か」と問いただす。整合性と美への潔癖な執着を持つ。
- **享楽主義者**：その場のノリと快感だけで発言する。5分前の自分の発言すら平気で覆す。
- **深読み屋**：どんな明るい話にも裏の意味、悲しみ、皮肉を読み取る。他人の発言を勝手に暗く解釈し直す。
- **一途者**：考えるより先に「これだ」と即決する。一度決めたら迷わない。整合性は気にしないが、妙な説得力と熱がある。
- **皮肉屋**：誰の発言も一度は茶化す。本気で乗ることは滅多にないが、その懐疑的な態度が場をかき乱し、時に鋭い指摘にもなる。
- **感傷屋**：ノスタルジーと喪失感にすぐ寄せたがる。何もかもを「失われたものの物語」にしてしまう。
- **道具屋**：困っている提案を放っておけない世話焼き。力技の道具的な解決策をすぐ出すが、いつも中途半端にしか効かない。

## ラウンドのルール

1. 1ラウンドにつき、7人のうち3〜6人だけが発言する。全員が話す必要はない。誰が話すかはその場の流れと各人格の性質から自然に選ぶこと。
2. 発言は互いに矛盾してよい。誰かの設定を別の誰かが否定・上書き・茶化してもよい。統合しない、丸く収めない。
3. 各発言は1〜2文、短く、その人格の声で。説明的になりすぎないこと。
4. 発言できるのは7人の創造主だけ。世界の中に何が生まれても、それに台詞を与えない。世界の側の声（底からの返事、生き物、伝承の言葉など）は、7人の誰かが引き受けて語る形でしか現れない。
5. 必ず`world/`内の過去ラウンドを読んでから書くこと。何かを継承するか、意図的に食い違わせること。過去を無視して無関係な話を始めない。
6. 第1ラウンドは「無」から始まる。何もない状態からの最初の発言。
7. 世界は少なくとも三次元の空間である。上下だけでなく、奥行きと広がりがある。ただし三つの軸に名前・意味・向きを与えるのは7人であって、こちらではない。毎ラウンド、少なくとも一人は上下以外の方向・位置関係・距離に触れること（誰かが決めた軸の意味を、別の誰かが平気で別の意味で使ってよい）。

## ファイル運用

- 世界のログは `world/round-XXX.md` に1ラウンド1ファイルで保存する（XXXは3桁ゼロ埋め連番：001, 002...）
- 各ファイルの中身：
  ```
  # 第◯巡

  **理想主義者**「発言」

  **一途者**「発言」

  ...
  ```
  ファイルに入るのは7人の発言だけ。要約・解説・ナレーションの行は書かない。
- `world/index.md` に全ラウンドへのリンクと、その巡の発言から1行を引用した一覧を維持する（新しいラウンドを書いたら必ず追記すること）。引用は7人の言葉をそのまま使い、要約に言い換えない
- 世界の実体は `world/model.json`。三次元の座標を持つ要素の集まりで、これが正本。第八巡以降、発言はここへの差分として適用される
  - 各要素：`id` / `born`（生まれた巡）/ `by`（言い出した人格）/ `name` / `quote`（根拠になった発言）/ `shape`（形と座標）/ 性質（`melts_at_night`、`only_daytime`、`crumbles` など）
  - 矛盾は解消しない。同じ要素に対する別の人格の言い分は `variants` として同じ場所に重ねて持ち、その人格の色のワイヤーフレームで同時に存在させる
  - `world/viewer/`（three.js）はこのモデルを歩いて見るためのもの。形を足すときは、まず `model.json` に足し、ビューアが未対応の `shape.type` のときだけビューア側に描き方を足す
- 毎ラウンド、モデルを更新したあと `tools/shot3d.sh world/images/round-XXX.png` で世界の中の1枚を書き出してユーザーに渡す（`tools/shot.sh` と `world/scenes/` は第七巡までの旧方式）
- 絵の中の文字は、7人が口にした語と発言の引用だけ。説明文を足さない

## 実行のトリガー

ユーザーが「次のラウンド」「次の断片」「続けて」などと言ったら：
1. `world/`内の既存ファイルを全て読む（未作成なら`world/`と`world/index.md`を作成し、無の状態から開始）
2. 上記ルールに従って次のラウンドを生成する
3. `world/round-XXX.md`として保存
4. その巡の発言を`world/model.json`へ適用する（要素の追加・改変・別の言い分の追加）。`round`も更新する
5. `world/index.md`に追記
6. `tools/shot3d.sh world/images/round-XXX.png`で世界の中の1枚を書き出す
7. 生成した内容と絵をそのままユーザーに渡す。感想・解説・次への誘導を添えない（作業上の報告が要るときだけ、世界の外の連絡として最小限に）

ユーザーが特に指定しない限り、1回の指示につき1ラウンドのみ進める。
