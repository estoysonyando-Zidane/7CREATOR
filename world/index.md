# 世界の年代記

第五巡以降は、その時点の世界の様子を1枚の絵として `world/images/round-XXX.png` に残す（元データは `world/scenes/round-XXX.html`、書き出しは `tools/shot.sh`）。

| 巡 | この巡の変化 |
|---|---|
| [第一巡](round-001.md) | 無に最初の光が灯り、それを覆いきれない蓋が同時に生まれた。 |
| [第二巡](round-002.md) | 蓋の縁から漏れる光が固められて最初の足場となり、そこが住む場所と呼ばれはじめた。ただし暗がりでは溶ける。 |
| [第三巡](round-003.md) | 足場が溶ける周期に昼と夜という名がつき、夜に沈んだものは二度と同じ形では戻らなくなった。 |
| [第四巡](round-004.md) | 夜の前に一日ひとつだけ形を写す枠が生まれ、何を残すかという最初の選別が始まった。 |
| [第五巡](round-005.md)<br>[絵](images/round-005.png) | 選ばれなかった形が沈殿して世界の底層となり、枠の番人が一途者から享楽主義者へ移った。 |
| [第六巡](round-006.md)<br>[絵](images/round-006.png) | 枠に耳がつき、選ばれた形の音が沈殿層の底まで届くようになった。潜った者からの返事はまだない。 |
| [第七巡](round-007.md)<br>[絵](images/round-007.png) | 底を通った音が反響として戻りはじめ、皿の上で一度だけ形になって崩れるようになった。 |
