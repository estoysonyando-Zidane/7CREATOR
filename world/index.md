# 世界の年代記

| 巡 | この巡の変化 |
|---|---|
| [第一巡](round-001.md) | 無に最初の光が灯り、それを覆いきれない蓋が同時に生まれた。 |
| [第二巡](round-002.md) | 蓋の縁から漏れる光が固められて最初の足場となり、そこが住む場所と呼ばれはじめた。ただし暗がりでは溶ける。 |
| [第三巡](round-003.md) | 足場が溶ける周期に昼と夜という名がつき、夜に沈んだものは二度と同じ形では戻らなくなった。 |
| [第四巡](round-004.md) | 夜の前に一日ひとつだけ形を写す枠が生まれ、何を残すかという最初の選別が始まった。 |
